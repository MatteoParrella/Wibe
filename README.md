# ⚡ WIBE - Event Radar & PR Management

**WIBE** è un'applicazione web ad alte prestazioni costruita con **Next.js 15** e **Supabase**, progettata per connettere PR e Clubber. Offre una mappa interattiva (Radar) per scoprire eventi in tempo reale e una dashboard dedicata ai PR per gestire la creazione di eventi e il monitoraggio dei ticket emessi.

---

## 🚀 Caratteristiche Principali

- 📍 **Live Event Radar**: Mappa interattiva con Leaflet per localizzare serate e club.
- 👤 **Dual Role System**: Accesso differenziato per **Clubber** (prenotazione pass) e **PR** (gestione eventi).
- 🎫 **QR Code Generation**: Generazione automatica di QR Code per ogni ticket scaricato.
- 📊 **PR Dashboard**: Monitoraggio in tempo reale del numero di partecipanti per ogni evento creato.
- 🌑 **Cyberpunk UI**: Interfaccia scura con accenti verde acido, ottimizzata per il mobile.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Database & Auth**: [Supabase](https://supabase.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Maps**: [Leaflet.js](https://leafletjs.org/)
- **Icons**: Lucide React
